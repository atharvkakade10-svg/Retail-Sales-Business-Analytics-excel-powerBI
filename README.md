# Retail-Sales-Business-Analytics-excel-powerBI
Project Overview

An end-to-end retail sales and business performance analytics project using Microsoft Excel and Power BI.

The objective of this project is to analyze retail sales data, evaluate business performance, identify revenue and profit trends, and generate actionable business insights.


Tools Used:

Microsoft Excel

Microsoft Power BI

Power Query


DAX


Project KPIs

KPI

Total Revenue -  1,230,208,737 Rs.

Total Profit  -  328,457,743 Rs.

Total Orders  -  24,342

Profit Margin -  26.70 %



Project Workflow

1. Data inspection and cleaning using Excel.

2. Data validation and handling missing values.

3. Exploratory data analysis using PivotTables.

4. Data transformation using Power Query.

5. Data modelling and relationship creation in Power BI.

6. DAX measures for business KPIs.

7. Dashboard development and business insights.


Power BI Dashboard - 

The dashboard includes:

1. KPI cards for revenue, profit, orders and profit margin.

2. Monthly revenue trend analysis.

3. Regional revenue contribution.

4. Category-wise revenue and profit analysis.

5. Top 10 products by revenue.



Key Business Insights:

The West region contributes approximately 80.23 % of total revenue.

Electronics generates the highest revenue among product categories.

The overall profit margin is 26.70%.



Conclusion:

This project demonstrates practical skills in data cleaning, exploratory analysis, data modelling, DAX calculations, dashboard development and business insight generation using Excel and Power BI.
